# Amplitude

> Amplitude is an all-in-one AI analytics platform combining product, web, and agent analytics; session replay and heatmaps; experimentation and feature flags; guides and surveys; activation; data governance; and AI feedback and agents. Product, engineering, data, and marketing teams use it to understand behavior and improve digital experiences.

Page titles link to HTML; adjacent Markdown links provide text versions.

## Install Amplitude

- [Create an account](https://amplitude.com/get-started) ([Markdown](https://amplitude.com/get-started.md)): Reuse an existing organization or sign up; confirm US or EU storage before creating an organization.
- [Choose a project](https://amplitude.com/docs/get-started/create-project) ([Markdown](https://amplitude.com/docs/get-started/create-project.md)): Select the target project and obtain its public ingestion API key and region.
- [Preferred browser SDK](https://amplitude.com/docs/sdks/analytics/browser/browser-unified-sdk/get-started) ([Markdown](https://amplitude.com/docs/sdks/analytics/browser/browser-unified-sdk/get-started.md)): Use `@amplitude/unified` for new browser apps with a bundler; one initialization entry point for analytics, replay, experimentation, and guides and surveys.
- [Agent installation workflow](https://amplitude.com/install.md): Use the CLI to retrieve the integrating-amplitude skill; follow its stack-specific implementation and verification steps.
- [Other platforms](https://amplitude.com/docs/sdks) ([Markdown](https://amplitude.com/docs/sdks.md)): Native mobile, cross-platform, and server SDKs; alternative browser installations.
- [Verify and troubleshoot](https://amplitude.com/docs/analytics/debug-analytics) ([Markdown](https://amplitude.com/docs/analytics/debug-analytics.md)): Trigger an action and confirm its specific event in the intended project; report evidence or the blocker.

## Developer and agent tools

- [Amplitude CLI](https://amplitude.com/docs/developers/cli) ([Markdown](https://amplitude.com/docs/developers/cli.md)): Fetch setup skills and automate supported platform operations; SDKs instrument the application.
- [Amplitude MCP](https://amplitude.com/docs/amplitude-ai/amplitude-mcp) ([Markdown](https://amplitude.com/docs/amplitude-ai/amplitude-mcp.md)): Query account data and work with charts, dashboards, and other resources through OAuth. US: `https://mcp.amplitude.com/mcp`; EU: `https://mcp.eu.amplitude.com/mcp`.
- [Docs MCP](https://amplitude.com/docs/api/mcp): Public, read-only documentation lookup; no authentication.
- [HTTP API specification](https://amplitude.com/openapi.json): Operations, schemas, regional servers, and authentication. Use SDKs or the ingestion API to send events.
