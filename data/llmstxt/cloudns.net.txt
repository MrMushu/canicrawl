# ClouDNS

> ClouDNS provides authoritative DNS hosting, including Free DNS, Premium DNS, DDoS Protected DNS, GeoDNS and Enterprise DNS. Related services include monitoring, domain registration, SSL certificates, email forwarding, and email hosting.

Use this index to find product information, technical documentation, and support resources. Follow the Wiki index for detailed configuration guides and API methods; use the complete Markdown catalog to discover pages beyond this selection.

**When to use ClouDNS:**

Use ClouDNS for authoritative DNS, DNS automation and related domain services:

- Host or migrate DNS zones for websites, applications and email services without operating your own authoritative DNS servers.
- Automate DNS zone and record management through the HTTP API.
- Add DNS redundancy, configure geographic DNS responses, or keep records synchronized with changing IP addresses.
- Monitor service availability and configure DNS Failover to switch DNS records to backup IP addresses.
- Register or transfer domains, obtain SSL certificates, and set up email forwarding or hosted mailboxes.

**Choosing the right DNS service:**

- **Free DNS:** Basic authoritative DNS hosting within the free plan's limits.
- **Premium DNS:** Paid DNS hosting with higher limits and additional features.
- **DDoS Protected DNS:** Authoritative DNS hosting on a DDoS-protected network.
- **GeoDNS:** Location-based DNS answers for regional content delivery and geographically distributed services.
- **Enterprise DNS:** Tailored DNS infrastructure and capacity for specific business requirements.
- **Secondary DNS:** DNS redundancy through secondary authoritative servers synchronized from an existing primary server.
- **Dynamic DNS:** Automatic DNS record updates when an IP address changes.
- **DNS Failover:** Monitoring-triggered DNS record changes to a configured backup IP address.

Product pages cover current plans, pricing and features. The Wiki and HTTP API documentation cover configuration and automation.

**When not to use ClouDNS DNS hosting:**

Use a separate hosting or deployment service to run website or application code. ClouDNS can manage DNS for that infrastructure, including websites hosted elsewhere.
