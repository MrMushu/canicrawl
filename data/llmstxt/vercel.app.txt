# Vercel

> Vercel is the agentic infrastructure company. It is a cloud platform where developers and agents build, ship, and run AI agents and applications. Vercel is the team behind Next.js and AI SDK.

## How agentic infrastructure works

Deploy it, run it, and let agents keep improving it.

### 1. Deploy

Push your website, agent, backend, or container to git, or tell Claude Code, Codex, Cursor, or OpenCode to ship it. Every part of Vercel works the same for you and your agents. Ship from the CLI, the dashboard, or any coding agent, and never think about the infrastructure underneath.

### 2. Run it, and pay only for what it uses

Fluid compute runs your app and agents, and Sandbox runs the code they generate. Both pause Active CPU charges while code waits on model responses. AI Gateway routes model calls at provider token prices with no markup. Hobby plans include free monthly allowances, and Pro plans bill additional usage on demand.

### 3. Let agents keep improving it

Vercel Agent can review and create pull requests when you ask it to, investigate production issues, and test generated code in sandboxes. It is read-only by default. Before it changes your deployments or settings, it presents a scoped plan and waits for your approval. Build your own agents with eve for everything else.

## For coding agents and AI tools

Set up from a terminal:

```bash
# Deploy the current directory
npm i -g vercel
vercel login
vercel

# Plugin for Claude Code, Codex, Grok Build, Cursor, Copilot, Kimi Code
npx plugins add vercel/vercel-plugin

# Plugin for OpenCode
opencode plugin add github:vercel/vercel-plugin

# Skills for any other agent
npx skills add vercel-labs/agent-skills

# Let your agent manage projects, deployments, and logs
npx -y add-mcp https://mcp.vercel.com -g

# Route your agent's model calls through AI Gateway
npx vercel ai-gateway setup
```

- [Vercel MCP server](https://vercel.com/docs/agent-resources/vercel-mcp.md): OAuth-authenticated tools for docs, projects, deployments, and logs, at `https://mcp.vercel.com`.
- [REST API](https://vercel.com/docs/rest-api.md) and its [OpenAPI description](https://vercel.com/openapi.json): Endpoints for projects, deployments, domains, and other account resources.
- [Vercel CLI](https://vercel.com/docs/cli.md): Deploy, inspect, and manage projects from a terminal.
- [Vercel Plugin](https://vercel.com/docs/agent-resources/vercel-plugin.md): Skills, commands, and specialist agents for the coding agents above.
- [Vercel Skills](https://vercel.com/docs/agent-resources/skills.md): Vercel-published skills for React and Next.js, AI SDK, deployment, and more, each with its install command. Machine-readable index: [agent-skills index](https://vercel.com/.well-known/agent-skills/index.json).
- [Claim deployments](https://vercel.com/docs/deployments/claim-deployments.md): An agent deploys an app for a user, then transfers it to the user's own Vercel account.
- [AI Gateway model list](https://ai-gateway.vercel.sh/v1/models): Live JSON list of every model, with pricing. No API key needed.
- [Markdown access](https://vercel.com/docs/agent-resources/markdown-access.md): Add `.md` to a vercel.com URL, or request the usual URL with the HTTP header `Accept: text/markdown`.

## Questions teams ask before they start

### Can a coding agent sign up and deploy to Vercel?

Yes. Point Claude Code, Codex, Cursor, or another agent at vercel.com/get-started.md. It installs the Vercel CLI, creates an account with vercel signup if needed, connects Vercel MCP, and deploys, pausing only for steps that need your approval.

### Does Vercel run Python, containers, and backends?

Yes. Python is generally available for FastAPI, Flask, and Django. Node.js, Go, and Bun run natively, the Container Runtime (beta) runs any Dockerfile, and Services deploys frontend and backend together with private networking.

### How does Vercel price compute for AI workloads?

Fluid compute bills active CPU, provisioned memory, and invocations, not wall-clock time. An agent that waits 30 seconds on a model but uses 300 ms of CPU pays for 300 ms of CPU. AI Gateway charges provider token prices with no markup.

### How does Vercel keep agent-generated code safe?

Vercel Sandbox runs untrusted code in an ephemeral Firecracker microVM with its own kernel, filesystem, and network. Secrets can be injected through a proxy, so code can use credentials without reading them.

### Will my code be locked in to Vercel?

No. Vercel maintains open-source frameworks including Next.js (90M+ weekly npm downloads, November 2026), the AI SDK (45M+), and eve (1M+). Your code stays standard TypeScript, Python, Go, or a container you can run anywhere.
