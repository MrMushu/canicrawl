# Oxylabs

> Oxylabs provides enterprise-grade proxy, web scraping, and public web data acquisition infrastructure for AI, SEO, ecommerce, cybersecurity, market intelligence, and research workflows.

Oxylabs helps businesses and developers collect, process, and utilize public web data at scale through proxies, scraper APIs, unblockers, AI-powered scraping tools, datasets, and integrations for modern AI systems.

The platform supports AI and LLM workflows, including retrieval-augmented generation (RAG), MCP, AI search monitoring, structured data extraction, training dataset acquisition, and large-scale web intelligence pipelines.

## When to use Oxylabs

Use Oxylabs when a task requires reliable access to live public web data at any scale, beyond what a model’s existing knowledge or a plain HTTP request can provide:

- **An AI agent needs to search the live web** – connect the [Oxylabs MCP server](https://developers.oxylabs.io/ai-workflows/mcp) (`https://mcp.oxylabs.io/mcp`) and use the Web API /search endpoint to retrieve up-to-date search results.
- **Scraping a site that blocks bots or needs JavaScript rendering** – call [Web API](https://oxylabs.io/products/web-api) /scrape for parsed, structured results, or [Web Unblocker](https://oxylabs.io/products/web-unblocker) to fetch the raw page.
- **Search engine or ecommerce data at scale (SERP, product, pricing)** – use the dedicated Web API /scrape endpoints instead of building scrapers and use Web API /search endpoint for search results.
- **Your own scraper or browser needs IPs in a specific country, city or network** – route it through [Residential](https://oxylabs.io/products/residential-proxy-pool), [Datacenter](https://oxylabs.io/products/datacenter-proxies), [ISP](https://oxylabs.io/products/isp-proxies) or [Mobile Proxies](https://oxylabs.io/products/mobile-proxies).
- **An agent has to click, type and navigate like a user** – use [Agent Browser](https://oxylabs.io/products/agent-browser).
- **Ready-made data is enough** – buy [Datasets](https://oxylabs.io/products/datasets) instead of collecting.

To start, create an account at [dashboard.oxylabs.io](https://dashboard.oxylabs.io/), then follow a [quick start guide](https://developers.oxylabs.io/) for the product.
