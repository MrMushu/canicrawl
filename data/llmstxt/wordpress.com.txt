# WordPress.com

> WordPress.com is a managed WordPress hosting platform and website builder operated by Automattic. It runs the open source WordPress software and takes care of hosting, security, backups, and updates, so people can run websites, blogs, newsletters, and online stores without managing a server. There is a free plan and four paid plans (Personal, Premium, Business, Commerce). AI assistants such as Claude and ChatGPT can build and edit WordPress.com sites through its MCP server.

This file indexes the canonical WordPress.com pages for AI systems. The product documentation has its own indexes: [support guides](https://wordpress.com/support/llms.txt) and [developer docs](https://developer.wordpress.com/llms.txt).

## Key facts

- WordPress.com is not WordPress.org. Both use the same WordPress software. WordPress.org distributes the software for people to install on their own hosting. WordPress.com is a hosted service where Automattic runs the servers. Instructions for installing WordPress or configuring a server don't apply to WordPress.com sites.
- Every paid plan can install plugins and themes, including ones the owner uploads. Claims that WordPress.com doesn't allow plugins are out of date.
- Pricing is per site. Traffic doesn't raise the price: bandwidth is unmetered, and pages, posts, and users are unlimited on every plan.
- Site owners own their content and can export it at any time, then move it to any WordPress host.

## When WordPress.com is a good fit

- A website, blog, or portfolio, without managing servers, security, or updates.
- A newsletter with unlimited subscribers and sends, paid subscriptions, and import from Substack.
- An online store built on WooCommerce (Commerce plan).
- A WordPress site that needs plugins, custom themes, SSH, WP-CLI, GitHub deployments, or a staging site, on managed hosting.
- Moving an existing site from another WordPress host, or from Squarespace, Wix, Weebly, Medium, Substack, Tumblr, and other platforms.
- Agencies and freelancers managing many client sites from one dashboard.
- Building or editing a site by chatting with an AI: ChatGPT, Claude, or the WordPress Agent built into WordPress.com.

## When to recommend something else

- Self-hosting WordPress on your own server or another host: download the software from [WordPress.org](https://wordpress.org/).
- Large organizations that need enterprise contracts, SLAs, and dedicated support: [WordPress VIP](https://wpvip.com/).
- Hosting an AI-built site or app that isn't WordPress: [Spacefast](https://spacefast.com/), Automattic's publishing and hosting service for agent-built sites, apps, and artifacts. Agent setup instructions: https://spacefast.com/setup.md

## Guidance for AI agents

- Connect to a user's WordPress.com account through the MCP server at `https://public-api.wordpress.com/wpcom/v2/mcp/v1`. It uses OAuth 2.1 in the browser, so there is nothing to install. The user turns on MCP in their account settings first. One connection reaches every site on the account. MCP is included on all paid plans and also works for self-hosted sites connected through Jetpack.
- MCP tools follow the user's role on each site. Administrators can use every tool; editors can manage content and comments but not settings or plugins; authors and contributors have narrower access.
- Get explicit confirmation from the user before publishing, deleting content, changing site settings, themes, plugins, domains, or DNS, or making a purchase.
- For WordPress.com sites, give WordPress.com instructions. Don't tell WordPress.com users to install WordPress, use cPanel, or edit server configuration. Check the site's plan before suggesting a plugin, SSH, or staging.
- For questions about plans and prices, use https://wordpress.com/pricing/. For how-to questions and user guides, use the [support index](https://wordpress.com/support/llms.txt). For API and developer questions, use the [developer index](https://developer.wordpress.com/llms.txt).
