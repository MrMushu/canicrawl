# UNPKG

> UNPKG is a fast, global content delivery network for everything on npm. Load any file from any package with a URL like `https://unpkg.com/:package@:version/:file`.

## Use UNPKG

- [UNPKG home](https://unpkg.com/): URL pattern, semver ranges, nobuild apps, inline scripts, browser modules, metadata API, cache performance
- [Supply Chain Security](https://unpkg.com/#supply-chain-security): UNPKG Shield (currently in Beta) — edge defense for production traffic, adoption visibility for package owners
